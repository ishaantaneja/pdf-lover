**PDF Lover** is a modern, blazing-fast web application that magically transforms your long, boring PDFs and SOPs into bite-sized, interactive microlearning lessons. No more scrolling through walls of text—just upload, swipe, and learn!

## ✨ Features

- **🧠 Intelligent Text Chunking:** Automatically breaks down long paragraphs and documents into readable "cards" without losing any content.
- **🚀 100% Client-Side:** Powered by `pdfjs-dist`, your PDFs are processed entirely in your browser. No API keys needed, and your data never leaves your computer.
- **📱 Mobile-Friendly Design:** A sleek, premium dark-mode interface with glassmorphism effects built to feel like a native mobile app.
- **💾 Local Storage Persistence:** Close the tab? No problem. Your generated lessons and reading progress are saved right to your browser.

## 🎨 Interface Preview

Enjoy a distraction-free learning environment with smooth transitions, progress tracking, and easy-to-use navigation.

> _"Turn that 50-page manual into an interactive flashcard deck in seconds."_

## 🛠️ Tech Stack

- **Frontend Framework:** React + Vite
- **Styling:** Premium Vanilla CSS (Dark Mode, Glassmorphism)
- **PDF Parsing:** `pdfjs-dist`
- **Icons:** Lucide React

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ishaantaneja/pdf-lover.git
   cd pdf-lover
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:** Navigate to `http://localhost:5173/` and drop your first PDF!
